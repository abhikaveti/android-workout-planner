# UAT Script — Competitive Physique

Use this checklist on your Android device.

## A. Installation
- [ ] Install debug build.
- [ ] Launch successfully.
- [ ] Close and reopen successfully.

## B. Plan
- [ ] Load sample plan.
- [ ] Confirm plan appears on Home.
- [ ] Confirm next workout appears.
- [ ] Import valid JSON.
- [ ] Validate preview.
- [ ] Save and activate.

## C. Workout
- [ ] Start workout.
- [ ] Enter set weight.
- [ ] Enter reps.
- [ ] Enter RIR.
- [ ] Save.
- [ ] Confirm completed set is displayed.
- [ ] Force-close app.
- [ ] Reopen and resume.

## D. Progression
- [ ] Complete workout.
- [ ] Confirm next workout changes.
- [ ] Skip a day.
- [ ] Confirm sequence is unchanged.

## E. Feedback to capture
For every issue, send:
1. Screen name
2. What you expected
3. What happened
4. Screenshot if possible
5. Steps to reproduce
